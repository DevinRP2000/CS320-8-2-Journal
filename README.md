## How can I ensure that my code, program, or software is functional and secure?
To ensure that my code, program, or software is function and secure is by relying on tests to ensure each function and branch meets it's intended functionality. During this course this was done by writing individual JUnit tests for each function, branch, and edge case to ensure the program is properly functional and secure. 

## How do I interpret user needs and incorporate them into a program?
I interpret user needs by making sure that I follow what the user needs while also ensuring that those needs make sense and don't conflict with one another. After getting the requirements from the user and making sure they make sense, I then strictly follow the requirements when writing them into a program. This way I ensure that I'm only adding what the user wants.

## How do I approach designing software?
When designing software I breakdown the main goal of a program into parts/units. For example, a game of snake can be broken down into multiple smaller parts, such as the snake, the apple, and the map. Those parts can then be further broken down such as the snake into the snake's movement and the snake's collision. Designing software this way allows me to work on smaller pieces that can then be combined into a full program.
